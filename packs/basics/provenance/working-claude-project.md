## 2026-09-28 · born · the repo is where the work lives; a Claude project holds only temporary artifacts
- **Source:** the owner, in a project thread: nothing is to be kept only in project folders except
  processing artifacts; the project is a tool that helps the repo grow, never the objective.
- **Reason:** days of detection work (finders, lab, labels, skill, ledger) lived only in a project's
  shared folder, and a fresh session from the repo could not see any of it.
- **Mechanism:** a prose rule; no deterministic check can tell a project folder's code from its
  artifacts.
- **Actor:** the owner (a process change).
